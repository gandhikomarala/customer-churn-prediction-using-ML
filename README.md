# ChurnGuard ML — Predictive Customer Retention Intelligence

Machine learning customer churn prediction studio with real-time SHAP feature importance, customer cohort risk sliders, LTV impact analysis, and automated retention playbook generation.

## Product Highlights
- **Domain**: Machine Learning
- **Visual Theme**: Obsidian Slate & Neon Fuchsia
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start

# Run Tests
pytest tests/

# Docker Deployment
